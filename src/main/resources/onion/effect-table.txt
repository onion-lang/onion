# The effect table (issue #356). Consulted by onion.compiler.effects.EffectTable.
#
# Format:   Class#method=effect[,effect...]     one method (all overloads)
#           Class#*=effect[,effect...]          every method of the class
#           Class#method=pure                   explicitly effect-free
# A specific entry beats the class wildcard. Anything not covered here is
# `unknown` — not known pure — and the reference page is docs/reference/effects.md.
#
# Vocabulary: read write net exec env clock rand console unknown
#
# Granularity is per-type, not per-instance: a PrintStream over a file is `write`,
# but in Onion code PrintStream means System::out/err, so it is classified console.
# Closure-running helpers (Future::async, Timing::measure) carry only their own
# effects; the closure body's effects are charged to the method that creates the
# closure (see EffectInference).
